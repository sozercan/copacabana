Resolves each tag to a digest and records one cluster-wide SourceImage per digest. Floating tags are listed, never swapped.

copa-builder · tainted node

copa-verifier · holds signing key
5Verify Job

Source layers kept as a prefix (8 kept, 2 added), config unchanged but a label, re-scan agrees with VEX. Builds the index, signs a DSSE attestation.

registry
6Published to patched/*

nginx:1.25.3-alpine-1 pinned by digest, attestation and VEX attached as referrers. About 25 s end to end.

2 · Roll it out separately in each namespace

controller
7Catalog check

Finds the newest -N revision; checks signature, subject, source digest and platforms. Anything unsigned or mismatched is ignored.

team namespace
8PatchRollout

One per namespace and source. A candidate that was rolled back once is never proposed again.

team namespace
9Approval

Automatic if the namespace allows it, otherwise a PatchApproval for the exact digest (kubectl copa approve).

team namespace · guarded by VAP
10SwapList updated

nginx:1.25.3-alpine and its aliases → patched/…@sha256. Only the controller may write it, only to pinned patched/* targets.

API server · MutatingAdmissionPolicy
11Restart and swap

Dry-run pod proves admission works, then a restartedAt bump (2 at a time). Each new pod's image is swapped as it's created.

controller
12Watch and soak

Pod spec and the node's runtime imageID must match the digest; pods stay healthy, then the group soaks → Succeeded.

3 · Back out at any point, including after Succeeded

trigger
Team or health

copa.sh/fail-rollout=true, or pods miss the deadline, crash-loop, or run the wrong image.

controller
Restore

SwapList goes back to the previous patch, or the source pinned by digest.

controller
Re-check

Restart again and verify the restored image is what's running.

outcome
RolledBack

Or RecoveryFailed. Other namespaces keep the patch.

Guardrails
  • The Deployment still says nginx:1.25.3-alpine; the swap happens only at pod admission.
  • Admission fails open (failurePolicy: Ignore): a pod that misses the swap gets the source image, and the missed-swap detector raises a metric and an event.
  • Job pods get no service-account token; only the verify Job sees the signing key; only signed patches reach a SwapList.
